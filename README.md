🎬 BingePlay – Streaming Platform Data Analysis

📌 Project Overview

BingePlay is a data analytics project focused on analysing streaming platform data to understand user behaviour, content preferences, subscription patterns and viewing engagement.

The project uses SQL for database management and querying, and Python for data analysis and visualization. It aims to generate meaningful business insights that can help improve user engagement, content recommendations and customer retention.

🎯 Project Objectives

* Analyse streaming platform user behaviour.
* Understand subscription distribution.
* Identify the most-watched content categories.
* Analyse device usage patterns.
* Identify top-rated shows.
* Evaluate user engagement and viewing habits.
* Generate actionable business insights.
* Present findings through data visualizations.
